SWARALIPI MITRA — PERSONAL PORTFOLIO WEBSITE

CONTENTS
- index.html: Home page
- about.html: Background, experience, education and tools
- services.html: Services and working process
- portfolio.html: Original demonstration writing samples
- blog.html: Filterable knowledge journal
- contact.html: Contact form
- articles/: Individual article pages
- assets/css/style.css: Responsive site styling
- assets/js/: Navigation, contact form and article rendering
- assets/images/profile.jpg: Supplied profile photograph

PREVIEW LOCALLY
1. Extract the ZIP archive.
2. Open index.html in a modern browser.
3. Keep the folder structure unchanged so page and asset links work.

CONTACT FORM
The contact form uses a mailto link to swaralipimitrafreelance1@gmail.com. It opens the visitor's email application with a prepared message; it does not send or store messages automatically. For a hosted form that collects messages without requiring the visitor's email app, connect a form service and update the form integration.

BEFORE PUBLISHING
- Confirm the email address is still the correct public business contact.
- Review all biography, education, service and experience wording. The site intentionally describes postgraduate study without claiming an unconfirmed completed qualification.
- Replace the profile photograph if you prefer another portrait.
- Review the demonstration articles and portfolio samples; they are self-initiated samples, not client commissions or peer-reviewed publications.
- Add links to professional social profiles only if you want them public.
- Test the site on a phone and desktop.

FREE HOSTING OPTION: GITHUB PAGES
1. Create a GitHub repository for the website.
2. Upload the contents of this folder so index.html is at the repository root.
3. Open repository Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to provide the published URL.

NOTES
- This is a static HTML/CSS/JavaScript website; it does not require a server or build step.
- Google Fonts need an internet connection; fallback fonts are provided.
- The contact form does not have a backend.
- No analytics or tracking scripts are installed.

ADDING A BLOG ARTICLE
1. Copy an existing article HTML file in articles/ and edit its title, category, date and body.
2. Add an article object to the articles array in assets/js/articles.js.
3. Use a category matching one of the filter labels in blog.html.
4. Test the article link and category filter locally, then upload the updated files.
