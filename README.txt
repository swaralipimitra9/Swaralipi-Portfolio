SWARALIPI MITRA — PERSONAL PORTFOLIO WEBSITE

This folder is prepared for the current GitHub repository layout, where HTML, CSS, JavaScript and image files are uploaded at the repository root.

PAGES
- index.html: Home
- about.html: About
- services.html: Services
- blog.html: Blog with ten subject categories
- portfolio.html: Portfolio
- contact.html: Contact

BLOG CATEGORIES
Management, Nutrition, Marketing, Psychology, Agriculture, Physiology, Anatomy, Geography, History and Literature.

FILES
- style.css: site styling
- main.js: shared navigation and contact interactions
- articles.js: blog categories and article listing
- profile.jpg: profile image

UPLOAD
Extract this ZIP and upload all files directly into the root of the GitHub repository. Choose to replace existing files when GitHub asks. Keep index.html at the root.

NOTE
Only three sample articles are currently included. The other category sections will display an empty-state message until articles are added.
